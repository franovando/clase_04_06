# Práctica: EDA de Datos Crediticios y Colaboración en GitHub

Este repositorio contiene un Análisis Exploratorio de Datos (EDA) aplicado a un conjunto de datos del sector financiero. El objetivo principal es identificar patrones, comportamientos de pago y factores socioeconómicos que se relacionan directamente con el puntaje crediticio (`Credit_Score`) de los clientes.

Además de los objetivos analíticos, este proyecto se utiliza como base para implementar un flujo de trabajo colaborativo utilizando Git y GitHub.

## 🎯 Objetivos del Proyecto

### 📊 Análisis de Datos (EDA)
* Realizar un análisis univariado de variables clave (edad, salario, utilización de crédito, tasas de interés).
* Explorar relaciones bivariadas y multivariadas para entender el impacto del comportamiento financiero en el perfil de riesgo del cliente.
* Detectar la presencia de valores extremos (outliers) y analizar correlaciones entre ingresos, préstamos y deudas pendientes.

### 👥 Dinámica de Trabajo Colaborativo
* **Gestión de tareas:** División y asignación del trabajo mediante GitHub *Issues*.
* **Estrategia de ramificación:** Desarrollo en ramas (*branches*) separadas para evitar conflictos.
* **Integración y revisión:** Apertura y discusión de *Pull Requests* (PRs) antes de fusionar el código a la rama principal.

## 🛠️ Herramientas Utilizadas

* **Lenguaje:** Python 3
* **Manipulación de datos:** `polars`
* **Visualización:** `seaborn`
* **Entorno:** Jupyter Notebooks
* **Control de versiones:** Git & GitHub
